# Credits

GITA is an immersive retelling of the Bhagavad Gita. The credits describe this project’s tools and references; they do not imply endorsement or copied source code.

## Technology

Created by Akanshu Jain with [OpenAI Codex](https://openai.com/codex/)-assisted development.

- [Three.js](https://threejs.org/): real-time 3D rendering.
- HTML, CSS and JavaScript: responsive interface, language selection and story navigation.
- Web Audio API: battlefield mixing and spatial sound.
- [ElevenLabs](https://elevenlabs.io/): generated narration and battlefield sound effects.
- Python: existing audio production, packaging and release utilities.

## Inspiration and text

- [Lusion's AI Quest](https://ai-quest.lusion.co/): immersive browser storytelling reference.
- [Astra](https://astra.directory/): immersive web experience reference supplied by the creator.
- [The Gateless Gate 3D](https://killedbyapixel.github.io/GatelessGate/#preface): flowing surroundings reference supplied by the creator.
- [Bhagavad Gita](https://vedabase.io/en/library/bg/): source linked by the experience. The dialogue is a retelling, with access to original Sanskrit.
